# WAXBALL 개인정보처리방침

버전: 1.2.0

시행일: 2026-09-07

공개 정책: https://waxball.akra.kr/privacy/

WAXBALL은 AKRA(akra-devs)가 운영합니다. 개인정보 문의는 help@akra.kr로
보내주세요. 소리·그래픽 설정, 보석 지갑,
볼 소장 여부와 플레이 진행 상태는 기기에 저장됩니다. WAXBALL은 AKRA 계정을
생성하지 않으며 이 로컬 설정을 AKRA가 운영하는 데이터베이스로 전송하지 않습니다.

광고가 활성화된 빌드에서는 Google Mobile Ads와 Google User Messaging Platform이
광고 제공·측정·부정행위 방지·개인정보 선택 제공을 위해 기기 또는 계정 식별자,
광고 ID, IP 기반 대략적 위치, 진단 정보, 앱 상호작용과 동의 선택을 처리할 수
있습니다. Google의 처리와 보관에는 Google 정책과 사용자의 동의 선택이 적용됩니다.
UMP가 필요하다고 판단한 경우 앱 설정에서 광고 개인정보 선택 화면을 제공합니다.

Android 앱은 Firebase Analytics로 볼 선택, 플레이 시작·완료, 보상 지급, 제한적인
3D 그래픽 준비·재시도·간편 그래픽 전환 및 광고 준비·표시 조건·표시 결과를 분석합니다.
광고 분석값은 광고 형식·앱 내 위치, 고정 단계·사유·숫자 오류 코드, 준비된 광고의
대기 시간 구간과 앱 버전·빌드·운영/테스트 구분으로 제한합니다. 3D 진단은 고정 오류
코드·준비 단계·씬 종류·품질 등급·재시도 구분으로 제한합니다. AdMob 연결을 통해
광고 노출과 수익 정보도 처리할 수 있습니다. 앱은 이름·이메일·계정 ID·사용자 입력·
원본 터치 좌표·보석 잔액·원본 예외 메시지·stack trace·광고 응답 ID·기기 해시·원시
유입 주소를 Analytics 값에 추가하지 않습니다. 사용자가 복사한 진단 원문도 전송하지
않습니다. Firebase SDK 자체는 앱·기기 메타데이터와 앱 인스턴스 식별자를 처리할 수
있습니다. Analytics의 Android 광고 ID 수집과 광고 개인화 신호는 비활성화되어
있습니다. 보관과 삭제는 Firebase 및 Google Analytics 정책에 따릅니다.

웹 앱에는 이 Android 광고·Analytics·Crashlytics 수집 경로를 적용하지 않습니다.

Android 앱은 충돌, 앱 응답 없음(ANR), Flutter·Dart 미처리 오류와 일부 앱 시작
실패를 파악하기 위해 Firebase Crashlytics를 항상 사용합니다. Crashlytics는 충돌
stack trace, 관련 앱 상태와 기기 메타데이터, 앱·운영체제 버전, 기기 모델과 환경,
Crashlytics 설치 UUID, Firebase 설치 ID 및 세션 식별자를 처리할 수 있습니다.
WAXBALL이 추가하는 값은 검토된 고정 오류 코드와 앱 버전·빌드·채널, 대상 플랫폼,
설정 리비전, 화면 경로, 생명주기, 렌더러 종류·품질·세대, 오디오 포커스 및 작업
코드로 제한합니다. 이름·이메일·전화번호·계정 ID·사용자 입력·원본 터치 좌표·보석
잔액·인증정보·광고 동의 상태·원본 예외 메시지를 사용자 정의 값으로 보내지 않으며
Crashlytics 사용자 ID도 설정하지 않습니다. Google은 Crashlytics 보고서와 관련
식별자를 90일 보관한 뒤 삭제 절차를 시작한다고 안내합니다.

기기에 저장된 WAXBALL 데이터는 운영체제의 앱 데이터 삭제 기능 또는 앱 삭제로
제거할 수 있습니다. 앱 삭제는 이후 Crashlytics 수집을 중단하지만 이미 전송된
보고서의 보관 기간을 즉시 단축하지는 않습니다.

## 선택적 새 소식 알림 및 출석 보상

새 소식 알림을 켜면 Firebase Cloud Messaging(FCM)이 Firebase 설치 ID, 푸시 등록 토큰 및 전송 관련 정보를 처리하여 왁쓰볼 소식과 서비스 공지를 전달합니다. 앱은 앱·채널·언어별 주제를 구독합니다. AKRA는 등록 토큰을 로그로 남기지 않으며 보석 잔액과 출석 기록을 FCM에 전송하지 않습니다. 앱 환경 설정이나 Android 설정에서 알림을 끌 수 있습니다. 앱에서 알림을 끄면 자동 등록을 중단하고 FCM 토큰 삭제를 요청합니다. 오프라인이면 다음 연결 시 다시 시도합니다. 출석 날짜와 보석 지급 기록은 기기에만 저장되며 앱 데이터를 삭제하면 없어집니다.

수신한 소식은 현재 앱 실행 중에만 보관합니다. 서명된 공지는 GitHub Pages에서 HTTPS로 내려받으며, 기본 연결 정보는 GitHub의 개인정보처리방침에 따라 처리될 수 있습니다.
